# Rankawat Dairy Farm v1
Offline Android app for daily milk khata.
Features: owner PIN, seller details, daily milk entries, automatic amount calculation, monthly reports, print-to-PDF through Android print dialog, and JSON backup/restore.
No INTERNET permission.
Build with Android Studio or a compatible Android Gradle environment: ./gradlew assembleDebug
APK: app/build/outputs/apk/debug/app-debug.apk
