# Rankawat Dairy Farm — Bitrise-ready project

This is the Android project in normal Gradle layout. It includes a lightweight Gradle 8.9 launcher that downloads Gradle on the Bitrise machine, so no gradle-wrapper.jar is required in this package.

Bitrise settings:
- Project type: Android
- Root directory: .
- Module: app
- Variant: debug

The build output is app/build/outputs/apk/debug/app-debug.apk.
